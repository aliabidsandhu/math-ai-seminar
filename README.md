# Mathematics & AI Seminar Series website

A simple, independent static website for GitHub Pages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `math-ai-seminar`.
2. Upload `index.html` and `seminars.js` to the repository root (not inside another folder).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Once published, the website should appear at `https://YOUR-USERNAME.github.io/math-ai-seminar/`. GitHub will show the actual address in the Pages settings.

## Update talks
1. Open `seminars.js` in GitHub and click the pencil icon.
2. Add a new seminar entry following the commented example, or edit an existing entry.
3. Commit changes. The public site will update after GitHub Pages deploys.
4. Change `status` to `past` to move a seminar to the archive.

## Update other text
Edit `index.html` directly on GitHub and commit changes.

## Before publishing
- Replace or remove any provisional information.
- Confirm organizers' names and permission to publish their details.
- Obtain permission before using institutional logos or implying university endorsement.
- Avoid publishing private Zoom meeting passwords.
- For a more user-friendly editor later, consider a static-site CMS or a no-code platform.
